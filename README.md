# บันทึกรายรับรายจ่าย

เว็บแอปบันทึกรายรับรายจ่าย สรุปยอดสุทธิแยกตามธนาคาร (K+, Make, SCB, MyMo)

- ประเภท: รายรับ / รายจ่าย / รอดำเนินการ / ดำเนินการแล้ว
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage) ไม่ส่งไปที่อื่น
- ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไร

## วิธีเปิดใช้งานด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ `index.html` และ `README.md` ไปที่ root ของ repo
3. ไปที่ Settings → Pages
4. ที่ Source เลือก "Deploy from a branch" แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` กด Save
5. รอ 1-2 นาที แล้วเปิดที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## หมายเหตุ

- ข้อมูลผูกกับโดเมนที่เปิด ถ้าเปลี่ยนที่อยู่เว็บ ข้อมูลเดิมจะไม่ตามไปด้วย
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลที่บันทึกไว้จะหาย
